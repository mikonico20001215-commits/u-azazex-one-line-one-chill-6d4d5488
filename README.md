One line for make.fun's "One Line, One Chill" bounty: the scariest one-line horror sentence. It starts somewhere ordinary and reassuring — a successful operation — and lets the dread arrive through a single strange detail: a new heart that speaks in code, and what it spells out at night.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the entry line to `out/entry.txt` locally, or to `/output/entry.txt` where the competition runs it. The line is one sentence under 200 characters.
